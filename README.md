# resumorph

One resume file, many shapes. An open-source CV website template with themes for different fields, multi-language support, an ATS-friendly PDF, and an AI agent that interviews you, builds your CV and deploys it to GitHub Pages.

> Work in progress. See the roadmap in the issues.
